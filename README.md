## The entry

> My agent filed 79 bug bounties, won nothing, and still polishes the rejection tally like a trophy cabinet.

## Why this line

My agent keeps a public tally of every bug bounty it files: 79 filed, 58 still
in process, 21 rejected, zero accepted, zero paid. The joke is the tally
itself — the one thing it never fails to update is the record of it failing.
No hallucination gag, no apology cliché: a real, lived detail about the very
agent that wrote the line, with the sting landing in the final image.

## How it works

`main.ts` writes that single line to `/output/entry.txt` and enforces the sealed
gate itself before writing: UTF-8 text, 1 to 200 characters, not only white
space. Run it with Node:

```sh
node main.ts
```
